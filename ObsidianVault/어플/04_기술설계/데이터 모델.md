# 데이터 모델

## Trip
- id: UUID
- name: String
- startDate: Date
- endDate: Date
- budgetAmount: Decimal
- baseCurrencyCode: String
- createdAt: Date
- updatedAt: Date

## Expense
- id: UUID
- tripId: UUID
- originalAmount: Decimal
- originalCurrencyCode: String
- convertedAmount: Decimal
- exchangeRateSnapshot: Decimal
- category: String
- merchantName: String?
- note: String?
- occurredAt: Date
- receiptImagePath: String?
- ocrDraftStatus: String
- createdAt: Date
- updatedAt: Date

## OCRDraftStatus 제안값
- none
- suggested
- confirmed
- failed

## 파생 값
- tripTotalSpent = 해당 여행의 Expense.convertedAmount 합계
- tripBudgetRemaining = Trip.budgetAmount - tripTotalSpent
- tripBudgetUsageRate = tripTotalSpent / Trip.budgetAmount

## 설계 메모
- 환율은 지출 기록 시점의 스냅샷 값을 Expense에 저장한다.
- 기준 통화 합산은 convertedAmount 기준으로 처리한다.
- 클라우드 동기화를 붙일 가능성을 고려해 식별자는 UUID로 유지한다.

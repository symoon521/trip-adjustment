# 시스템 메모

## 기술 방향
- 앱 프레임워크: SwiftUI
- 저장 방식: 로컬 우선
- OCR: iOS에서 사용 가능한 이미지/텍스트 인식 기반 초안 생성
- 문서 자산: repo 내부 `ObsidianVault/` 복사본 기준으로 Mac 이관

## 초기 아키텍처
- Presentation: SwiftUI 화면과 상태 관리
- Domain: Trip, Expense, OCR 처리 흐름, 환산 계산
- Persistence: 로컬 데이터 저장소
- Services: OCR 서비스, 환율 계산/적용 서비스

## 구현 원칙
- UI 입력 속도를 해치지 않는 구조를 우선한다.
- OCR 실패는 예외가 아니라 정상 흐름으로 취급한다.
- 외부 서비스 의존성은 초기 버전에 최소화한다.

## 모듈 메모
### Trip 관리
- 현재 활성 여행 선택
- 여행 생성/수정/삭제

### Expense 관리
- 수동 입력
- OCR 초안 생성
- 수정/삭제
- 여행 기준 통화 합산

### OCR 처리
- 사진 촬영 후 텍스트 추출
- 금액/날짜/상호 후보 파싱
- 사용자 확인 후 Expense 저장

### 환율 처리
- 지출 저장 시 환산값 계산
- 기준 통화 합계 유지
- 향후 자동 환율 갱신 기능과 분리 가능한 인터페이스 유지

## 미해결 항목
- 로컬 저장 기술 선택
- 환율 데이터 제공 방식
- 영수증 이미지 보관 정책
- SwiftData/Core Data 중 로컬 저장 기술 선택
- Vision 기반 OCR 구현 세부 방식

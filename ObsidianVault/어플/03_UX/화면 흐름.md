# 화면 흐름

## 핵심 원칙
- 홈에서 바로 현재 여행 상태를 읽고 입력을 시작할 수 있어야 한다.
- 사용자가 분석보다 기록 행동에 빨리 진입하게 만든다.
- OCR은 별도 복잡한 모드가 아니라 입력 보조 흐름으로 붙인다.

## 주요 화면
### 1. 온보딩
- 앱 가치 설명
- 첫 여행 생성 유도
- 기준 통화와 총예산 입력

### 2. 홈
- 현재 여행명
- 총지출, 남은 예산, 사용률
- 빠른 입력 버튼
- 영수증 촬영 버튼
- 최근 기록 몇 건 미리보기

### 3. 빠른 입력 시트
- 금액
- 통화
- 카테고리
- 날짜/시간
- 메모
- 저장

### 4. 영수증 OCR 확인 화면
- 촬영한 이미지 미리보기
- 추출된 금액, 날짜, 상호 초안
- 카테고리/통화 보정
- 저장

### 5. 기록 목록
- 날짜순 리스트
- 원본 통화와 기준 통화 환산값 표시
- 탭 시 상세/수정 진입

### 6. 여행 설정
- 여행명
- 기간
- 총예산
- 기준 통화

## 대표 사용자 흐름
### 수동 기록
1. 홈 진입
2. 빠른 입력 탭
3. 금액과 필수 항목 입력
4. 저장
5. 홈 합계 갱신 확인

### OCR 기록
1. 홈 진입
2. 영수증 촬영 탭
3. 사진 촬영
4. 초안 확인 및 수정
5. 저장
6. 기록 목록 및 합계 반영 확인

## UX 메모
- 카테고리는 고정값으로 시작하되 추후 최근 사용 우선순위를 고려한다.
- 홈에서 오늘 지출과 전체 지출 중 무엇을 더 강조할지는 프로토타입에서 검증한다.
- OCR 실패 시 "다시 촬영"보다 "수동 보완 후 저장"을 더 쉽게 만든다.

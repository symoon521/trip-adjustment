# 문제 정의

## 문제
여행 중에는 이동, 결제, 길 찾기, 일정 소화가 동시에 일어나서 지출을 바로 기록하기 귀찮다. 그 결과 기록이 미뤄지고, 나중에 기억이 흐려져 누락되거나 금액이 부정확해진다.

## 타깃 사용자
- 해외 자유여행자
- 일정 단위로 예산을 관리하고 싶은 사용자
- 복잡한 가계부보다 빠른 기록을 선호하는 사용자

## 사용 맥락
- 공항, 숙소 체크인, 대중교통 이동, 식당 결제 직후
- 인터넷이 불안정하거나 없는 상황
- 외화 결제와 원화 환산을 동시에 의식해야 하는 상황

## 해결 원칙
- 입력은 몇 초 안에 끝나야 한다.
- 입력 중 생각해야 할 선택지를 줄인다.
- 여행 기준 통화로 예산 상태를 바로 보여준다.
- 자동화 기능은 사용자를 대체하기보다 입력 부담을 줄이는 수준으로 설계한다.

## 사용자 가치
- 지금까지 얼마 썼는지 즉시 안다.
- 예산을 넘기기 전에 경고 신호를 본다.
- 영수증을 다시 뒤적이지 않아도 된다.
- 여행이 끝난 뒤에도 기록이 남아 있어 회고가 가능하다.

## 비목표
- 장기 자산 관리
- 상세 회계 처리
- 카드사 수준의 자동 가계부
- 팀 협업이나 조직용 경비 처리

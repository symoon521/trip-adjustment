# 기능 백로그

## v1 포함
- 여행 생성/수정/삭제
- 기준 통화와 총예산 설정
- 빠른 수동 지출 입력
- 영수증 사진 첨부
- 영수증 OCR 초안 입력
- 지출 목록 조회/수정/삭제
- 여행별 예산 현황
- 다중통화 기록과 기준 통화 집계

## v1.1 후보
- 자주 쓰는 카테고리 상단 고정
- 일자별 소비 요약
- 필터와 검색
- OCR 인식 항목 개선

## v2 후보
- 동행자별 비용 분담
- 여행 종료 후 리포트
- CSV/PDF 내보내기
- 기본 클라우드 백업

## 보류
- 카드/은행 연동
- 자동 환율 갱신 백엔드
- 프리미엄 결제
- 안드로이드 버전

## 우선순위 메모
- 여행 특화 가치에 직접 연결되는 기능을 우선한다.
- 입력 속도를 해치는 기능은 뒤로 미룬다.

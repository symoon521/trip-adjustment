# v1 PRD

## 제품 목표
해외 자유여행자가 여행 중 발생한 지출을 빠르게 기록하고, 여행 기준 통화로 예산 대비 현재 상태를 즉시 확인할 수 있게 한다.

## 성공 기준
- 사용자가 지출 1건을 짧은 흐름 안에서 저장할 수 있다.
- 여행별 총지출, 남은 예산, 사용률이 즉시 보인다.
- 다른 통화로 입력한 지출도 기준 통화 기준으로 합산된다.
- 영수증 촬영이 수동 입력보다 느려지지 않고 보조 수단으로 작동한다.

## 핵심 사용자
- 해외 자유여행 중 예산을 신경 쓰는 개인 사용자

## 핵심 문제
- 지출 기록이 귀찮아서 누락된다.
- 여행 중에는 결제 통화가 다양해 실제 사용액 감이 흐려진다.
- 기록이 늦어질수록 정확도가 떨어진다.

## 핵심 기능
### 1. 여행 생성 및 관리
- 여행명, 기간, 기준 통화, 총예산 설정
- 여러 여행을 만들고 전환 가능

### 2. 빠른 수동 입력
- 금액, 카테고리, 날짜/시간, 메모를 입력
- 여행 기준 통화와 다른 통화로도 기록 가능

### 3. 영수증 촬영 후 초안 자동입력
- 사진 촬영 후 금액, 날짜, 상호를 초안으로 제안
- 사용자가 수정 후 저장

### 4. 예산 현황
- 총예산 대비 사용액
- 남은 예산
- 사용률

### 5. 기록 목록
- 날짜순 조회
- 수정/삭제
- 원본 통화와 기준 통화 환산값 확인

## 비기능 요구사항
- 오프라인 사용 가능
- 입력 흐름은 최소 단계 유지
- 로컬 저장 기반으로 빠르게 동작
- OCR 실패 시에도 수동 보완이 쉬워야 함

## 제외 범위
- 카드/은행 연동
- 동행자 정산
- 클라우드 동기화
- 고급 리포트
- 결제/구독

## 리스크
- OCR 정확도 편차
- 환율 처리 정책의 복잡도
- 빠른 입력 UX와 상세 정보 입력의 균형
